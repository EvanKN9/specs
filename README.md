# PartsFoundry

PartsFoundry is an interactive React/Vite proof-of-concept (OPTION 2) for CS4800
Software Engineering class project.

The prototype demonstrates a guided PC-building workflow:

1. Define a build brief
2. Generate a recommended configuration
3. Inspect compatibility
4. Replace components
5. Review the effects of component changes

## Running the Prototype

Requirements:
- Node.js
- npm

Install dependencies:

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
